# 💰 Salary Calculator

一个基于 Flet 的桌面工资计算器，支持 **累计预扣法个税计算**、**五险一金**、**大病医疗保险**、**加班费**、**按天工资** 和 **预算分配管理**。

## ✨ 功能

### 📊 工资计算
- 基本工资 + 加班费（周末 2 倍、节假日 3 倍）
- 独立加班基数
- 五险一金（自定义比例）
- **大病医疗保险（默认 10 元/月）**
- 专项附加扣除
- **累计预扣法个税**（2019 年新规，全年综合所得级距）
- 按天计算（首月/离职场景，自动获取工作日数据）

### 📋 预算分配
- 三大类：必要支出 / 弹性支出 / 储蓄投资
- 多种分配方案：50/30/20、631、333
- 自定义方案
- 子项管理：权重分配、实际支出对比、实时差额
- **稳定排序**：按类别 + 序号，刷新不乱

### 📈 月度记录
- 全量快照存储（45+ 字段）
- 历史查看
- 期初/期末结余自动串联
- **一键导出 CSV**（UTF-8-BOM，Excel 直接打开不乱码）

### 📊 年度汇总
- 按年聚合：应发合计 / 五险一金 / 个税 / 实发 / 额外收入
- 总支出、储蓄、储蓄率、年末结余
- 月度明细表

### 🛡️ 数据安全
- 启动时自动备份数据库到 `backups/`（每天一份，保留 30 天）
- 社保比例（养老/医疗/失业）可在界面配置，政策变化无需改代码

## 🚀 快速开始

### 环境要求
- Python 3.10+
- Flet 0.86+

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/sesveria/salary-calculator.git
cd salary-calculator

# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

### 首次使用
1. 打开后在 **工资计算** Tab 填写月份和薪资参数
2. 点击「计算」预览，点击「保存」
3. 切换到 **预算分配** Tab，选择月份，点击「生成细项」
4. 调整各项预算金额，点击「保存」
